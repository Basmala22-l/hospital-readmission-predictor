# 🏥 30-Day Hospital Readmission Risk Prediction for Diabetic Patients

An end-to-end Machine Learning web application designed to predict 30-day hospital readmission risk for diabetic patients at discharge time, helping care teams plan proactive follow-up interventions.

## 🔗 Live Demo
- Try the live web application here: [Streamlit App](https://hospital-readmission-predictor-ac7jcfmpprsqk2vappceucr.streamlit.app/)

## 📌 Project Overview
Hospital readmissions within 30 days for diabetic patients are costly and often indicate gaps in post-discharge care. This project builds an automated decision-support tool using clinical data to identify high-risk patients before they leave the hospital.

## 📊 Results Summary
- **Baseline Model:** Majority class baseline established.
- **Best Machine Learning Model:** Optimized pipeline with robust feature engineering, achieving high recall to catch at-risk patients effectively.
